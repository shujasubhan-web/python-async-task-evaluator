# Async Task & Code Evaluator 🚀

An asynchronous Python API built with **FastAPI** and **Pytest** for code evaluation, performance testing, and execution scoring.

## 🛠️ Features
* **Async Performance:** Built with FastAPI and `asyncio` for non-blocking execution.
* **Data Validation:** Strict request/response modeling using Pydantic.
* **Automated Scoring:** Dynamic score calculation based on execution time and memory limits.
* **Unit Testing:** Fully tested using Pytest and FastAPI TestClient.

## 💻 Tech Stack
* **Language:** Python 3.10+
* **Framework:** FastAPI
* **Testing:** Pytest
* **Data Validation:** Pydantic
